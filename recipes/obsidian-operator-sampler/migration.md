# Migration guide

1. Inventory note types, frontmatter keys, inline fields, templates, queries,
   attachments, plugins, and automations without copying content here.
2. Map each old status and key to the canonical schema in `README.md`.
3. Copy five non-sensitive representative notes into a disposable vault and
   transform those first.
4. Reconcile links, dates, tasks, people, projects, embeds, and query results.
5. Back up the source, run the full transform on a copy, and keep a rollback.
6. Move only after a human samples the result and the old vault stays readable.

Do not let an agent bulk-rewrite the only copy of a vault.
