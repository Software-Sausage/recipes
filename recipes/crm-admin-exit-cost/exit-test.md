# CRM exit test

Use synthetic or approved representative data.

- [ ] Build one pipeline with people, organizations, deals, owners, activities, notes, files, custom fields, permissions, automation, and a report.
- [ ] Export every supported object using the plan and role you intend to buy.
- [ ] Open the export without the vendor and record missing objects or unreadable fields.
- [ ] Import into a clean test destination.
- [ ] Reconcile record counts, IDs, relationships, owners, timestamps, history, and attachments.
- [ ] Inventory workflows, reports, dashboards, integrations, credentials, roles, and configuration the export did not carry.
- [ ] Time the work and estimate full migration labor.
- [ ] Name the owner and rollback point before approving a purchase or cutover.

An archive is not a migration until the working state can be reconstructed and
verified.
